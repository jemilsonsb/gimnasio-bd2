# Backend

API Express del sistema de gestion de gimnasio.

## Configuracion

1. Copiar `.env.example` como `.env`.
2. Completar las credenciales de `gimnasio_bd2`.
3. Ejecutar `npm install`.
4. Ejecutar `npm test`.
5. Ejecutar `npm run dev`.

## Autenticacion

- `POST /api/autenticacion/registro`
- `POST /api/autenticacion/login`
- `GET /api/autenticacion/sesion`

Los nombres de tablas y columnas siguen el esquema real en espanol y minusculas.
